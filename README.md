# Steasy
Steasy is a modern, full-stack web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) designed to streamline the rental and booking experience—simulating an Airbnb-style platform with a focus on ease, speed, and reliability.

🌟 Key Features
User Authentication & Authorization: Secure sign-up, login, and role-based access control for guests and hosts using JWT (JSON Web Tokens) and bcrypt.

Property Listings & Management: Hosts can easily create, update, and manage property listings with detailed descriptions, pricing, and image uploads.

Advanced Search & Filtering: Allows users to search for properties based on location, price, availability, and specific amenities.

Seamless Booking System: A smooth reservation workflow enabling guests to book properties for specific timeframes with real-time availability checks.

Responsive User Interface: Built with React to provide a fluid, mobile-friendly user experience across all devices.

RESTful API Architecture: Robust backend services built with Node.js and Express to handle data transactions safely and efficiently with MongoDB.

🛠️ Tech Stack
Frontend: React.js, Tailwind CSS / CSS3, React Router

Backend: Node.js, Express.js

Database: MongoDB, Mongoose

Authentication: JWT, bcrypt.js
